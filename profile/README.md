# Herzlich willkommen bei der Lowlevel-Community!

Du möchtest ein eigenes Betriebssystem schreiben oder verstehen, was unter der Haube passiert? Dann bist du hier genau richtig. Hier auf GitHub führen wir die Lowlevel-Community nach dem Umzug von lowlevel.eu weiter – mit unserem Wiki, euren Fragen und den gemeinsamen Projekten.

Im [Wiki](https://github.com/lowlevel-eu/wiki/wiki) findest du Wissen vom ersten Bootsektor bis zum Betriebssystemdesign. Du kannst dort weiter an Artikeln arbeiten und sie verbessern. Fragen, Ideen und Austausch haben jetzt in den [Discussions des Wiki-Projekts](https://github.com/lowlevel-eu/wiki/discussions) ihren Platz – sie ersetzen das bisherige Forum. Die alten Beiträge bleiben im [schreibgeschützten Forum-Archiv](https://lowlevel-eu.github.io/forum/index.html) zum Nachlesen erhalten.

Auch der Code ist mit umgezogen:

- [týndur](https://github.com/lowlevel-eu/tyndur) – das Community-Betriebssystem von Lowlevel.
- [tutorial](https://github.com/lowlevel-eu/tutorial) – der Beispielkernel zur Artikelserie „OS-Dev für Einsteiger“.
- [libfat](https://github.com/lowlevel-eu/libfat) – eine Bibliothek zum Zugriff auf FAT-Dateisysteme.
- [libext2](https://github.com/lowlevel-eu/libext2) – eine Bibliothek zum Zugriff auf ext2-Dateisysteme.
- [lbuilds](https://github.com/lowlevel-eu/lbuilds) – Buildsystem und Patches für auf týndur portierte Programme.
- [help](https://github.com/lowlevel-eu/help) – das Hilfeprogramm für týndur.
- [cdi](https://github.com/lowlevel-eu/cdi) – das Common Driver Interface für betriebssystemunabhängige Treiber.

Ob du gerade anfängst oder schon länger an deinem Kernel bastelst: Stell Fragen, teile dein Wissen und mach mit! :)
